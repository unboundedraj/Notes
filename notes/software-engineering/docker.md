# Introduction:

---

**Docker** is an open-source platform that packages an application and all its dependencies **(code, runtime, libraries, configuration)** into a standardized unit called a **container**.

This eliminates the classic ***"it works on my machine"*** problem by guaranteeing that software runs identically across local development, staging servers, and cloud environments.

Before containers, running software predictably across different environments (a developer's laptop, a testing server, and a cloud production server) was difficult because variations in operating system versions, installed libraries, or local settings caused unexpected bugs.

## What is Docker Image?

 Just like a class behaves as a blue print to create objects in OOPS, similarly **docker image** is a blue print that helps us **create multiple containers**

This is a file that basically has instructions to build containers   
# So in rl, we don't share containers across our large team but rather this Docker image using which everyone creates their own containers

# Just like a class doesn't occupy a lot of space but rather the objects that were created using the class, similary docker image barely takes up storage but rather the containers that are build using that docker image.
